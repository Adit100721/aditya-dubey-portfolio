HOW I WORK / AI AGENTS

Focused agents. Thoughtful engineering.

I build focused Codex agents into my development workflow to run tests, assist with commits, review Java logic, and check the small interface details that affect usability.

  • 01

    Testing & regression

    Runs tests and regression checks, reporting results and failures so I can verify changes and investigate issues.

  • 02

    Commit assistance

    Assists with commit preparation and the check-in workflow, helping bring development changes into the review process.

  • 03

    Java logic review

    Flags newly introduced Java logic that may be unused or unreferenced in the current files, so I can review whether it belongs or needs integration.

  • 04

    UI detail checks

    Checks small interface changes, including whether buttons work correctly, where controls are placed, and how the layout fits together.

I use the findings to review whether the logic, behavior, and proposed changes are appropriate.
