# Aditya Dubey — Software Developer

A personal portfolio featuring core banking APIs, OBP middleware, API lifecycle orchestration, HDFC Net Banking engineering, and customer-data migration work.

The website includes a 3D developer workspace, blue-and-white and Slate Ice themes, project case studies, contact links, and a downloadable résumé.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. No build step or package installation is required.

## GitHub Pages

In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose **main**, select **/ (root)**, and save. The `.nojekyll` file keeps the site as plain static assets.

GitHub displays the public website URL in the Pages settings after deployment. All asset paths are relative, so the website also works beneath a repository path.

## Make changes

- Update page copy and project case studies in `index.html`.
- Update theme and shared styles in `assets/portfolio.css`.
- Update the interactive developer workspace in `assets/developer-lab.js` and its companion CSS.
- Replace `assets/Aditya-Dubey-Resume.docx` to update the résumé download.
- Commit and push changes to `main`; GitHub Pages publishes the update.
